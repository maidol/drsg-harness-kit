# Agent 执行效率：运维与敏感文件细则（按需读取）

> 命令报告磁盘不足/ENOSPC、需要对生产数据或外部服务运行写操作，或需处理可能含凭据的文件时，读取本文件对应部分。常驻规则中关于密钥值和凭据文件的保护要求仍然适用。

## 磁盘空间

报满先 `df -h`。可以自己清 Go 构建缓存（`go env GOCACHE` 确认后 `go clean -cache`），清完继续原任务，回执里写清了多少；还不够、或要删缓存以外的东西，才停下问。

## 运维脚本：碰生产数据的，默认只看不改

默认试运行，不加 `--apply` 不写库、不调外部接口；写库前打印备份命令，生产上带 `--apply` 的那次由用户执行。真实账号、邮箱、域名、主机名不进代码、测试、文档和提交（示例用 `example.com`、`.test`）。只提交送审清单里的文件。

## 密钥：值不出现在任何输出里

API key、token、密码、私钥的**值**不进终端输出、文件、提交、PR、Fact、Event，只写变量名或 `<hidden>`。验证鉴权用假值或只断言形状；用 env 里的值时 `set -a; . <env 文件>; set +a`，不 `cat` env 文件、不跑 `env`/`printenv`、不用 `curl -v`。万一打印出来：立刻告诉用户留在了哪里，建议轮换，删掉落盘副本。Fact 写入不经过任何检查。

凡是可能带凭据的文件（MCP 配置、settings、`~/.claude.json`、各类 env、密钥文件，不限于这几种）都不整段打印或 Read：看结构用 `jq` 只取键名或不含密钥的字段（`jq '.mcpServers | keys'`、`jq '.mcpServers[] | {type, url}'`），判断某个键在不在用 `grep -c 键名`。动手前先问：需要的信息能不能从工具名、会话记录或键名里拿到。全局钩子 `sensitive-file-read-guard` 会拒绝这类读取；被拒时按理由里的替代写法改，不要换个命令绕过去。读配置的命令单独发一条，不和 `git status`、审计、`cmp` 混在一起：一处被拒整条都不跑。改 settings、`~/.claude.json` 用 `jq '<filter>' f > f.new && mv f.new f`，或写成脚本请用户用 `!` 运行。
